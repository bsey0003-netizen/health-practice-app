# Health Practice App

A free, non-commercial revision app for MCAST students taking **ASPHY-406-1505 Anatomy for Health Practice**. It is an educational resource for student coursework only.

Students open the app link on their phone and add it to their home screen. Progress is stored only on the student's own device; nothing is collected or sent anywhere.
